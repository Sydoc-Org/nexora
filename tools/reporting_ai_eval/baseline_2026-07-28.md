# Baseline: 2026-07-28, INT, gpt-4o-mini

All 22 prompts tested against the live agent on INT, each judged independently
(a separate judge agent per case, reading the full response + tool trace)
against the `good` criterion in `prompts.json`.

**Overall: 6.1/10 average** - strong date math and real statistical methods
when it lands, but three blank replies and a lot of "one table presented as
the whole truth."

## What the run exposed beyond the scores

- **Blank-bubble bug (the biggest one):** 3 of 22 replies were completely
  empty. Two (#12, #21) ended after one turn with no tools and no text - the
  endpoint returns `stoppedReason: final` with an empty `answer`, and the chat
  panel would render an empty bubble. -> issue #127 (closed/fixed).
- **Single-table tunnel vision:** the recurring quality killer. Agent picks
  one process table (`Compass_Invoice`, `BFH_Statistic`) or
  `DPSLicenseCounter` and presents it as company-wide truth - 6+ cases. The
  curated docprocessing union exists precisely to avoid this; the agent
  prefers raw SQL over it. -> issue #128 (closed/fixed).
- **Sandbox friction burns turns:** the row-cap wrapper rejecting
  `ORDER BY`/`PERCENTILE_CONT` patterns cost many turns across cases and
  outright killed prompt #3. -> issue #129 (closed/fixed).
- **Server crash:** first attempt at prompt #18 hard-killed the dev server (no
  traceback, process gone, connection reset). Retry worked. One data point.
  -> issue #130 (open).
- **Genuinely strong:** date-window math was near-flawless everywhere
  (partial periods, YoY, German, half-open bounds), and it reaches for real
  methods - `LAG`, order-statistic medians, 3-sigma, calendar CTEs - instead
  of faking stats in prose.

Since this baseline was recorded, issues #127, #128 and #129 have shipped
fixes. A fresh `run_eval.py` run followed by re-scoring against
`prompts.json` is the only way to confirm the fixes actually move the
average - this baseline is the "before" half of that comparison, not a
currently-accurate description of the agent's behavior.
