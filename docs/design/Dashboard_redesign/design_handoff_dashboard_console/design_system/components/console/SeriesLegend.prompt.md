Sits in the right slot of a SectionRule or ChartHeader. Colours come from `--nx-series-1..5`; line style must match the chart.

```jsx
<SeriesLegend items={[
  { name: '02_Posteingang', color: 'var(--nx-series-1)', dash: 'solid', count: 612 },
  { name: '03_Invoice_New', color: 'var(--nx-series-2)', dash: 'dashed', count: 341 }
]} />
```
