{{ _("Getting Started") }}

{{ _("The nexora external API is a read-only JSON API for machine-to-machine integrations, authenticated with per-client API keys. All endpoints live under the v1 base URL and answer to GET requests only.") }}

{{ _("Base URLs") }}

{{ _("Environment") }}{{ _("Base URL") }}
PRODhttps://nexora.sydoc.ch/nexora/api/v1
INThttp://127.0.0.1:8000/api/v1

{{ _("Keys are not shared across environments: INT and PROD each run their own NexoraDB, so a key issued on one gets a uniform 401 on the other — same as an unknown key. Issue a key separately for each environment you need.") }}

{{ _("Quick start") }}

{{ _("One header, one GET — with an API key in hand, this is the whole integration:") }}

curl 
curl -H "Authorization: Bearer <api key>" \
    https://nexora.sydoc.ch/nexora/api/v1/stats/today
{{ _("response") }} 
{
  "date": "2026-07-22",
  "imported_today": 123,
  "exported_today": 117,
  "processes": ["sydoc.05_PDBS"]
}

{{ _("In PowerShell use curl.exe — bare curl is an alias for Invoke-WebRequest, which spells the header differently. No key or a wrong key returns") }} 401 {"error": "Invalid API key"}.

{{ _("Authentication") }}

{{ _("Send your API key as a Bearer token on every request:") }}

GET /api/v1/stats/today
Authorization: Bearer <api key>

{{ _("Keys are issued per client by the Sydoc team. Each key carries a process scope: it only ever sees the numbers of the processes it was issued for. The raw key is handed over once through a secure channel and is not recoverable afterwards — store it safely.") }}

{{ _("Key lifecycle") }}

  • {{ _("Keys do not expire on their own; they stay valid until revoked.") }}
  • {{ _("Revocation is effective immediately on the next request.") }}
  • {{ _("A revoked or unknown key answers a uniform 401 — deliberately indistinguishable, so a leaked key confirms nothing.") }}
  • {{ _("Rotation: request a new key from the Sydoc team, switch your integration, then the old key is disabled.") }}

{{ _("Rate limit") }}

{{ _("60 requests per minute per source IP, checked before authentication. Exceeding it returns HTTP 429; back off and retry after the minute window.") }}

GET/api/v1/stats/today

{{ _("Today's imported and exported document counts, scoped to your key's processes — the same numbers as the nexora dashboard's \"today\" KPI tiles.") }}

curl 
curl -H "Authorization: Bearer <api key>" \
    https://nexora.sydoc.ch/nexora/api/v1/stats/today
{{ _("response") }} 200 
{
  "date": "2026-07-14",
  "imported_today": 123,
  "exported_today": 117,
  "processes": ["sydoc.05_PDBS"]
}

{{ _("Response fields") }}

{{ _("Field") }}{{ _("Type") }}{{ _("Meaning") }}
