{{ _("Quick start") }}

{{ _("One header, one GET — with an API key in hand, this is the whole integration:") }}

curl 
curl -H "Authorization: Bearer <api key>" \
    https://nexora.sydoc.ch/nexora/api/v1/backlog
{{ _("response") }} 
{
  "datetime": "2026-08-04 09:15",
  "current_backlog": 154
}

{{ _("In PowerShell use curl.exe — bare curl is an alias for Invoke-WebRequest, which spells the header differently. No key or a wrong key returns") }} 401 {"error": "Invalid API key"}.

{{ _("Authentication") }}

{{ _("Send your API key as a Bearer token on every request:") }}

GET /api/v1/backlog
Authorization: Bearer <api key>

{{ _("Keys are issued per client by the Sydoc team. Each key carries a process scope: it only ever sees the numbers of the processes it was issued for. The raw key is handed over once through a secure channel and is not recoverable afterwards — store it safely.") }}

{{ _("Key lifecycle") }}

  • {{ _("Keys do not expire on their own; they stay valid until revoked.") }}
  • {{ _("Revocation is effective immediately on the next request.") }}
  • {{ _("A revoked or unknown key answers a uniform 401 — deliberately indistinguishable, so a leaked key confirms nothing.") }}
  • {{ _("Rotation: request a new key from the Sydoc team, switch your integration, then the old key is disabled.") }}

}

{{ _("Response fields") }}

{{ _("Field") }}{{ _("Type") }}{{ _("Meaning") }}
avg_minutesfloat | null{{ _("Average minutes between import and export among rows exported today, rounded to 1 decimal. null if no matching rows exist yet today.") }}
avg_displaystring{{ _("Same figure pre-formatted: seconds under a minute, minutes under an hour, hours above — or \"—\" when null.") }}

{{ _("The response does not echo the process list — scoping happens at key issuance.") }} {{ _("Calculation: for each configured process/table, the average seconds between import and export among rows exported today; the per-source averages are then combined as a plain mean, not weighted by how many rows each source had. GET/api/v1/workitems

{{ _("Query workitems with the Workitems overview page's filters, scoped to your key's processes. Take a result's id to /api/v1/workitems/{id} for its document details.") }}

curl 
curl -H "Authorization: Bearer <api key>" \
    "https://nexora.sydoc.ch/nexora/api/v1/workitems?field=invoicenr&value=INV-2026-00123&op=eq"
{{ _("response") }} 200 
{
  "count": 1,
  "page": 1,
  "per_page": 40,
  "total_pages": 1,
  "workitems": [
    {
      "id": 78214,
      "status": "Done",
      "stage": "Delivery",
      "modified_at": "2026-08-04 10:02:11",
      "import_datetime": "2026-08-04 09:12:31"
    }
  ]
}

{{ _("Query parameters") }}

{{ _("Param") }}{{ _("Meaning") }}
workitem_id{{ _("Exact workitem-id match") }}
statusReady | In Progress | Done
stageImport | Extraction | Validation | Delivery
start_date / end_date{{ _("ISO datetime bounds on the last-modified timestamp; start inclusive, end exclusive") }}
process{{ _("Comma-joined subset of your key's process scope (default: all of it)") }}
field / value / op / comb{{ _("Repeated document-field filter pairs (max 10); field keys are lowercase without separators (invoicenr, esrreference, …) — fetch the live list from /workitems/fields; op: contains (default), ncontains, eq, neq, startswith, endswith; comb joins a pair to the previous ones with and (default) / or") }}
page / per_page{{ _("Paging; per_page accepts only 40, 100, 200, 500 or 1000 (default 40)") }}

{{ _("Every invalid value returns a 400 with a plain-English error — nothing is silently coerced. Unknown and sensitive field keys answer identically (400 Unknown field). import_datetime is filled where the process is mapped in the statistics DB and null otherwise. Doc-field matches honour the same per-process time window as the overview page's search.") }}
