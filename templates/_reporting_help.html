{{ _("Get the best results") }}

{{ _("Building a report") }}

  • {{ _("Watch the coverage badge (e.g. 2/5) on measures and categories: only part of the processes provide that field, and documents from the others land in the empty bucket. Hover it to see which. If a number looks too low, check the badge first.") }}
  • {{ _("Everything in one empty bucket? The breakdown field is not filled in for the processes you selected.") }}
  • {{ _("Not sure what a result means? Press “Ask Eddard about this report” under the insight card — Eddard then answers about the report on screen, not in general.") }}
  • {{ _("Pick a Report definition in the wizard footer to see your own measures and tile layout instead of the standard result — create them under Report definitions in the rail.") }}
  • {{ _("A report definition owns the whole result: add Eddard insight, Ask Eddard, Anomalies or Query as panel tiles if you want them, and pick a saved report under “Preview with” to build against real numbers.") }}
  • {{ _("Not sure which table a source really reads? Click its card in the Sources rail: List shows the tables it uses and their columns, Diagram draws the relationships between them.") }}
  • {{ _("Relative presets stay relative: a report saved with “This month” shows the current month on every run and in every scheduled mail. Schedule times are UTC.") }}
  • {{ _("To see which document fields extraction gets right, pick the “Field extraction quality” measure “Extraction correct %%” and break down by “Field”. Sort ascending and the worst field is the top row.") }}
  • {{ _("Two traps on that source. Use “Extraction correct %%”, not “Extracted %%” — the latter only asks whether the machine put anything in the box, and everything Octo fills automatically comes back fully extracted. And stay on “Field” rather than “Field (incl. unmapped)” or “Field (Octo raw name)”: those list all ~630 names Octo emits, 230 of them internal bookkeeping pinned at the maximum, so the chart is just flat lines along the top.") }}
  • {{ _("That source covers every customer whose process is onboarded in nexora. Break down by “Client” to compare them, or filter to one. Field names are translated to a shared vocabulary first, so whatever each client calls its invoice number lands on the same row — that is what makes the comparison meaningful. The process list only offers processes nexora has onboarded; Octo’s own internal process names are not reportable.") }}
  • {{ _("A field whose “Avg. 2nd-candidate confidence %%” sits close to its best-candidate confidence means the extractor was torn between two readings — usually more worth fixing than a field that is simply never found.") }}
  • {{ _("The chips above a result are editable: the Processes chip and any “is one of” filter open a checkbox picker — ticking everything removes the restriction.") }}
  • {{ _("Need more than a date range? “Filters (optional)” on the wizard’s Time step adds field/operator/value rows — contains, starts with, is empty and the rest. Each one lands on the result as a chip you can edit or remove without rebuilding the report.") }}
  • {{ _("Imports, exports and backlog in one chart: pick “Documents imported”, “Documents exported” and “Backlog” together, then break down by “Date” — one line per measure on a shared time axis.") }}
  • {{ _("The breakdown step shows the everyday fields first; “Show advanced fields” unfolds the rare and diagnostic ones (raw Octo names, validation statuses, owner and property numbers). The result table is always shown under the chart — “Hide table” collapses it.") }}
  • {{ _("Time charts stop at today: the period that contains today is faded/dashed because it is still filling up, months that haven’t happened aren’t drawn, and a backlog period nobody measured is a gap, not a zero. Backlog’s Total is the newest snapshot.") }}
  • {{ _("The palette button in the chart toolbar recolours each series and the title, and puts a series on its own right-hand axis — Backlog starts there by default so a few hundred stays readable next to tens of thousands. Picks are saved with the report.") }}
  • {{ _("Need exact control the wizard can’t give? “Advanced” in the left navigation opens the three-panel builder, and its SQL tab runs a read-only query when even that is not enough. A failed query names the reason from the database, and switching between Table and SQL clears the result so you never read the other mode’s numbers.") }}
  • {{ _("Fastest way to look inside a table: click its source card under Sources, expand the table, then “Query the first 100 rows” — the SQL tab opens on the right database with the query written and already run. The Target picker names the real databases; the nexora database itself is not a query target.") }}

{{ _("Checking a number") }}

  • {{ _("Click a chart bar or a table row to open the documents behind that number; the “Query” card beside the chart shows exactly how it was computed.") }}
  • {{ _("Click the ↑/↓ chip on the total to see which processes or categories drove the change since the previous period.") }}
  • {{ _("Own the report? Alt+click a bar to pin a note on that period (“mailroom outage”). It shows as a small triangle on the chart and in the Annotations list below for everyone the report is shared with.") }}
  • {{ _("Each measure gets its own total card, named after it — “Total · Documents imported”, “Total · Documents exported”. There is no combined number: the same document can be counted in both, so adding them up would not count anything real.") }}
  • {{ _("A card headed “Overall” instead of “Total” holds a rate or an average, which cannot be added up. It is the real figure across every document behind the report — not the chart’s numbers summed.") }}
  • {{ _("“Buckets” counts periods, not table rows. Break down by month and by field and each month contributes one row per field, so the average card switches to “Avg per row” and names how many values it averaged.") }}
  • {{ _("Documents with no date sit in no period, so the stat band and the chart both leave them out. Eddard’s summary says how many were set aside.") }}
  • {{ _("The ↑/↓ comparison chips compare a window shifted back by your range’s length in days — not the previous calendar period. Hover a chip for the exact dates.") }}
  • {{ _("Two people can see different totals on the same report: it always runs with the viewer’s own data access.") }}
  • {{ _("Charts cap at 50 axis values and 12 series — past the cap you get a partial chart or none at all; the table and exports always carry the full data.") }}

{{ _("Saving and sharing") }}

  • {{ _("Save writes back to the report you have open — the pencil next to the title renames it in place. A result that is not a saved report yet (a wizard run, an answer from Eddard) asks for a name and lands under My reports. To keep the original untouched, use ⋯ → “Save as copy”.") }}
  • {{ _("A report of yours that you have shared — with everyone or with named colleagues — is tagged “· shared” on its card. Named shares stay under My reports; only “shared with everyone” moves it to the Library shelf.") }}
  • {{ _("A scheduled email runs with the report owner’s data access — recipients see the owner’s numbers, not their own.") }}
  • {{ _("Delete a report you own: open its card’s “…” menu under My reports, or open the report and use ⋯ → Delete report. Shared copies and schedules go with it.") }}
  • {{ _("Dashboard cards are pieces of your saved reports: Add a card, pick a report and it opens in full — hover a KPI tile or the chart, or use the table’s button, to put that piece on the dashboard, or take the whole report. Cards follow the report’s data and filters; in edit mode each chart card has its own toolbar — chart type, forecast, colours & axes — and those tweaks stay on the card, the report is untouched. A dashboard uses the whole window width; “Present” shows it fullscreen — Esc leaves. The filter bar shows the reports’ own filters — click a chip to swap “This month” for “Last month” or narrow the processes, and every card follows; ↺ on the chip goes back.") }}
  • {{ _("In edit mode a tile can be dragged anywhere to rearrange it, and resized by its bottom-right corner grip: width snaps to the 12 grid columns, height to whole rows. Done saves the layout.") }}
  • {{ _("A dashboard’s library card previews its real layout — one small tile per card — plus a card count, so you can tell dashboards apart before opening one.") }}

{{ _("Asking Eddard") }}

  • {{ _("Eddard is the reporting assistant behind the chat panel — the little black hole in the top bar.") }}
  • {{ _("Name the measure, the time range and the processes: “invoices by process, last 3 months” beats “show me invoices”.") }}
  • {{ _("Check what Eddard built with “Open in builder” — the filters and process scope it chose are visible there before you trust the number.") }}
  • {{ _("Follow-ups work: the chat remembers the conversation, so “now only this quarter” refines the last answer.") }}
  • {{ _("When Eddard used tools, unfold “How the agent worked” to see the steps; if a “Continue” button appears, click it before rephrasing your question.") }}
  • {{ _("The answer-depth control sits at the bottom-left of the composer: Quick for a fast number, Balanced for everyday questions, Deep when the question is hard and you can wait.") }}
